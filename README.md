# 뉴스브리핑 (PWA) — API 키 없이 동작

매일 아침 자동으로 업데이트되는 뉴스 브리핑 앱입니다. 핸드폰 홈 화면에 앱처럼 설치해서 씁니다.
**AI(유료 API) 없이** 기사를 같은 사건끼리 묶고, 대표 제목·발췌·키워드 흐름으로 정리합니다.

- **국내:** 노동 · 정치 · 사회 · 경제를 **단기(최근 1주) · 중기(최근 6개월) · 장기(최근 3년)**로
- **해외:** 8개 지역의 **경제 · 전쟁·안보 · 정치** — 한국 언론의 국제 기사를 모아 번역 없이 한국어로
- **사설:** 조선 · 동아 · 중앙 · 한겨레 · 경향 · 한국일보 · 매일신문의 오늘자 사설을 **같은 주제끼리 나란히** 비교, 최근 7일 신문별 자주 다룬 단어
- **보도자료:** 정부 부처 · 한국은행 보도자료 모음
- **디자인:** 브라운 계열, 다크모드 지원

```
newsbrief/
├── web/                  ← 앱(PWA). 이 폴더가 그대로 웹사이트가 됩니다
│   ├── index.html · app.js · styles.css
│   ├── manifest.json     ← 홈 화면 설치 정보(이름·아이콘·바로가기)
│   ├── sw.js             ← 서비스워커(오프라인·캐시)
│   ├── icons/
│   └── data/             ← 생성기가 매일 만드는 브리핑 JSON
├── generator/            ← 뉴스 수집·정리 생성기 (Node.js)
├── archive/monthly/      ← 월간 자료 누적 (중기·장기 브리핑의 재료)
└── .github/workflows/daily.yml  ← 매일 05:23(한국시간) 자동 실행 + 배포
```

## 화면에 보이는 것

| 기간 | 내용 |
|---|---|
| **단기 (1주)** | 개요(기사 수·매체 수·가장 많이 보도된 이슈) → **많이 나온 키워드** + 최근 3일 늘어난 키워드 → **주요 이슈**(대표 제목, 발췌 문장, 매체별 다른 제목, 보도 기간, 보도자료 여부) → **일자별 흐름** → 관련 보도자료 |
| **중기 (6개월)** | 개요 → **키워드 흐름**(키워드별 월간 막대, 늘어난·줄어든 키워드) → **주요 흐름**(여러 달 이어진 이슈와 달마다의 제목) → **전환점**(달마다 가장 크게 보도된 이슈) |
| **장기 (3년)** | 중기와 같은 구성, 36개월. 전환점은 분기별 |
| **해외** | 지역 선택 → 경제 / 전쟁·안보 / 정치별 키워드와 이슈 카드 |
| **사설 · 오늘** | 7개 신문의 수집 현황 → **같은 주제, 신문별 사설**(두 신문 이상이 함께 다룬 주제마다 각 신문의 사설 제목·첫머리를 나란히) → 신문별 오늘 사설 전체 |
| **사설 · 최근 7일** | 신문별로 사설 제목에 자주 나온 단어 (하루씩 쌓여 7일치가 채워짐) |

이슈 카드의 **관련 기사**를 펼치면 원문 링크가 나옵니다.

### 사설 비교는 이렇게 만듭니다
- **수집:** 신문마다 구글뉴스에서 `사설 site:신문사주소` 로 최근 2일을 검색하고, 제목에 `[사설]` 이 붙은 글만 남깁니다. 네이버 키가 있으면 네이버 뉴스 검색 결과에서 해당 신문 사설을 더하고, 첫머리 발췌도 함께 보여줍니다.
- **같은 주제 묶기:** 사설 제목은 신문마다 표현이 크게 달라서, 제목 글자 유사도와 함께 '정부·국회'처럼 흔한 말을 뺀 핵심어가 겹치는지를 봅니다.
- **하지 않는 것:** 신문 성향을 미리 정해 두거나 사설의 찬반을 판정하지 않습니다. 제목과 첫머리를 나란히 보여주고 판단은 읽는 사람에게 맡깁니다.
- 신문 목록은 `generator/src/config.js` 의 `EDITORIAL_PAPERS` 에서 바꿀 수 있습니다. 어떤 신문이 '수집 안 됨'으로 계속 나오면 `npm run check-sources` 로 확인하세요(구글뉴스가 그 신문 사설을 색인하지 않는 경우 등).

### AI 없이 정리하는 방법
- **같은 사건 묶기:** 제목의 글자 단위 유사도로 기사를 묶고, 기사 수·매체 수·보도자료 여부로 중요도를 매깁니다.
- **대표 제목:** 묶음 안에서 다른 제목들과 가장 비슷한(가운데) 제목. `[종합]` `[속보]` 같은 꼬리표는 뗍니다.
- **발췌 요약:** 네이버 검색 결과·보도자료에 들어 있는 기사 첫머리 중, 이슈의 핵심 단어를 가장 많이 담은 1~2문장. (구글뉴스는 발췌가 없어 네이버 키가 있으면 요약이 훨씬 풍부해집니다.)
- **키워드:** 제목에서 조사를 떼고 자주 나온 단어를 셉니다. 검색어로 쓴 단어(노동, 노조 등)는 당연히 많으므로 뺍니다.
- **여러 달 흐름:** 월별 주요 이슈들을 다시 유사도로 이어, 몇 달에 걸쳐 계속된 이슈를 찾습니다.
- **키워드 흐름:** 달마다 기사 100건당 몇 번 언급됐는지. 기간 앞 1/3과 뒤 1/3을 비교해 늘어난·줄어든 키워드를 표시합니다.
- 개요 문장은 숫자와 이슈 제목으로만 만들고, 해석이나 평가는 넣지 않습니다.

## 뉴스 소스

| 소스 | 방식 | 키 |
|---|---|---|
| **네이버 뉴스** | 공식 **뉴스 검색 API**(NAVER API HUB), 분야별 검색어 최신순. 네이버 메인 뉴스 화면은 공식 RSS·API가 없어 검색 API를 씁니다. | 네이버클라우드에서 무료 발급. 없으면 네이버만 빠짐 |
| **구글 뉴스** | RSS 검색. 중기·장기는 기간 검색(`after:`/`before:`)으로 월별 수집 | 필요 없음 |
| **중앙기관 보도자료** | 고용노동부·문화체육관광부 RSS + 구글뉴스로 부처 보도자료 보완. 정책브리핑(korea.kr) 통합 RSS는 2026-07-01 중단됨 | 필요 없음 |
| **한국은행** | 금통위 의결사항·의사록 RSS + 보도자료 RSS(주소 규칙으로 넣은 것이라 `npm run check-sources` 로 확인 필요) | 필요 없음 |

## 처음 설정 — GitHub에서 매일 자동 업데이트 (추천)

PC를 켜두지 않아도 GitHub가 매일 새벽 브리핑을 만들고 무료 HTTPS 주소(GitHub Pages)로 배포합니다. **비용 없음.**

1. **GitHub 저장소 만들기** → 이 폴더 전체를 올립니다.
2. **(선택) 네이버 키 등록:** 저장소 → Settings → Secrets and variables → Actions → *New repository secret*
   - `NAVER_HUB_KEY_ID`, `NAVER_HUB_KEY` (네이버클라우드 콘솔 → NAVER API HUB)
3. **Pages 켜기:** Settings → Pages → Source를 **GitHub Actions** 로
4. **지난 3년 자료 만들기 (한 번만):** Actions → *뉴스브리핑 매일 업데이트* → *Run workflow* → mode **backfill**
5. 이후 **매일 05:23(한국시간)** 자동 실행. 주소: `https://<아이디>.github.io/<저장소이름>/`

> 백필을 건너뛰어도 매일 실행이 최근 6개월은 자동으로 채웁니다. 장기(3년)는 백필을 해야 처음부터 꽉 찹니다.

## 핸드폰에 설치

GitHub Pages 주소를 폰 브라우저로 엽니다.

- **안드로이드(크롬):** 화면 위 안내의 **설치** 버튼, 또는 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
- **아이폰(사파리):** 하단 **공유(□↑)** → **홈 화면에 추가** (아이폰은 사파리에서만 설치됩니다)

## 내 PC에서 실행해 보기

Node.js 20 이상이 필요합니다(`node -v` 로 확인, 없으면 nodejs.org 에서 LTS 설치).

```bash
cd generator
npm install
cp .env.example .env        # (선택) 네이버 키 입력

npm run sample              # 디자인만 먼저 보기 — '예시' 데이터
npm run serve               # http://localhost:8080

npm run check-sources       # 소스 주소 점검
npm run backfill            # 지난 3년 월간 자료 (처음 한 번)
npm run daily               # 오늘 브리핑 생성 → web/data
```

일부만 다시 만들기: `node src/run.js --only=short,world` (monthly · short · mid · long · world · editorials)

## (선택) 나중에 AI 요약 켜기

키 없이도 앱은 그대로 동작합니다. 나중에 문장형 요약("왜 중요한가", "앞으로 볼 것" 등)을 원하면:

- GitHub: Secrets에 `ANTHROPIC_API_KEY` 추가 → 다음 실행부터 자동으로 AI 요약이 더해집니다(SDK는 워크플로가 알아서 설치).
- PC: `.env` 에 키를 넣고 `npm install @anthropic-ai/sdk`

키를 지우면 다시 자동 정리로 돌아갑니다.

## 바꾸고 싶을 때

| 바꿀 것 | 위치 |
|---|---|
| 분야별 검색어, 해외 지역·주제 검색어, 보도자료 피드 | `generator/src/config.js` |

| 업데이트 시각 | `.github/workflows/daily.yml` 의 `cron` (UTC 기준) |
| 앱 파일 수정 후 | `web/sw.js` 의 `VERSION` 을 올려야 설치된 앱이 새 파일을 받습니다 |

## 유의사항

- 기사·사설 원문 저작권은 각 언론사에 있습니다. 앱은 제목·링크와 짧은 발췌만 보여주고 원문은 언론사 페이지로 연결합니다.
- 자동 정리는 제목 유사도와 단어 빈도로 하므로, 서로 다른 사건이 한 묶음이 되거나 같은 사건이 둘로 나뉠 때가 있습니다.
- GitHub Pages는 공개 주소입니다. 혼자만 보려면 비공개 호스팅(Cloudflare Pages + Access 등)을 쓰세요.
